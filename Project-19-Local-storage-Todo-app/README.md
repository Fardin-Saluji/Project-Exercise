⏳ Project Exercise 19: Local Storage To-Do App

This project demonstrates how to build a to-do list application using HTML, CSS, and JavaScript.

📌 Description

The to-do app allows users to add, delete, and mark tasks as completed. Tasks are stored in the browser's local storage, so they persist even after the page is reloaded. JavaScript handles task creation, deletion, DOM updates, and saving/retrieving tasks from localStorage.

🛠️ Topics Covered

HTML
CSS
JavaScript

📚 Skills Covered

Using localStorage for persistent data storage

DOM manipulation to dynamically update the task list

Handling user input with event listeners
