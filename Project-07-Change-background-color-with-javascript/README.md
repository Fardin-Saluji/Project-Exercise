🎨 Project Exercise 7: Change Background Color with JavaScript

This project demonstrates the use of JavaScript to dynamically change the background color of a webpage through user interaction.

📌 Description

A button is added to the webpage, and when it is clicked, a JavaScript function is triggered to change the page’s background color. The project uses DOM manipulation to select the button and an event listener to handle the click event.

JavaScript

📚 Skills Covered

Basic JavaScript syntax

Functions and event handling

DOM selection and manipulation
