🖼️ Project Exercise 6: Responsive Photo Gallery with CSS Grid
This project demonstrates how to build a responsive photo gallery using HTML and CSS Grid. It focuses on creating a flexible layout that adapts smoothly to different screen sizes and devices.

📌 Description:-
The photo gallery displays images of varying sizes arranged in a CSS Grid layout. Media queries are used to adjust the number of columns based on screen width, ensuring the gallery looks well-organized and visually appealing on desktops, tablets, and mobile devices.

🛠️ Topics Covered:-
HTML,
CSS

📚 Skills Covered:-
CSS Grid layout management

Media queries for responsive design

Creating flexible and adaptive UI layouts
