⏳ Project Exercise 17: Countdown Timer

This project demonstrates how to build a countdown timer using JavaScript and DOM manipulation.

📌 Description

The countdown timer starts from a specified time and updates every second using setInterval(). The remaining time is displayed dynamically on the webpage. When the timer reaches zero, the countdown stops using clearInterval() and an alert notifies the user that the time is up.

🛠️ Topics Covered

JavaScript

DOM

📚 Skills Covered

Using setInterval() for periodic updates

Using clearInterval() to stop execution

Time calculation and manipulation

Updating the DOM dynamically
