📩 Project Exercise 2: Contact Us Form
This project focuses on creating a simple and user-friendly Contact Us form using HTML. It helps in understanding how forms work and how user input is collected on a webpage.

📌 Description:-
The form includes input fields for name, email, phone number, and a message, along with a submit button. Basic validation is applied using required attributes and appropriate input types to ensure correct and accessible user input.

🛠️ Topic Covered:-
HTML

📚 Skills Covered;-
HTML form creation
Input elements and attributes
Basic form validation
User-friendly and accessible form design
