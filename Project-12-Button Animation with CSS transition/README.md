🎯 Project Exercise 12: Button Animation with CSS Transitions

This project focuses on creating an interactive animated button using CSS to enhance user experience through smooth visual effects.

📌 Description

A button is designed to animate on user interaction. CSS transitions are used to make the button grow on hover and shrink when clicked. Animations are implemented using @keyframes along with transition properties like transform and scale to ensure smooth motion and responsive feedback. JavaScript may be optionally used for handling click events.

CSS

JavaScript (Optional)

📚 Skills Covered

CSS transitions

Animations using @keyframes

Using transform and scale properties

Creating smooth and interactive UI effects
