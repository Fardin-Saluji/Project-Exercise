🖼️ Project Exercise 16: Image Slider

This project demonstrates how to create a responsive image slider using HTML, CSS, and JavaScript with smooth automatic and manual navigation.

📌 Description

The image slider automatically cycles through images at a fixed interval using JavaScript timers. It also includes next and previous buttons that allow users to manually navigate between images. Event listeners handle user interactions, while DOM manipulation updates the displayed image. CSS transitions are applied to ensure smooth sliding animations, and the slider adjusts gracefully to different screen sizes.

HTML

CSS

JavaScript

DOM

📚 Skills Covered

JavaScript intervals for automatic transitions

Event listeners for next/previous navigation

DOM manipulation for dynamic image updates

CSS transitions for smooth animations

Responsive design techniques
