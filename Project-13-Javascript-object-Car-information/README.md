🚗 Project Exercise 13: JavaScript Object – Car Information

This project demonstrates the use of JavaScript objects to store and display structured data in a web application.

📌 Description

A JavaScript object is created to represent a car with properties such as make, model, and year. These properties are displayed dynamically on the webpage using document.write() or DOM manipulation techniques. The object is also logged to the browser console to show how object properties can be accessed and inspected.

🛠️ Topics Covered

JavaScript

📚 Skills Covered

Creating and working with JavaScript objects

Accessing object properties

Displaying data dynamically on a webpage

Logging objects and values to the console
