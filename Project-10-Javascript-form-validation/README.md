🧾 Project Exercise 10: JavaScript Form Validation

This project focuses on implementing client-side form validation using JavaScript to improve data accuracy and user experience.

📌 Description

The form includes input fields for name, email, and password. JavaScript is used to validate the inputs before form submission. Validation checks ensure that the name field is not empty, the email follows a valid format, and the password meets the required criteria such as minimum length. If validation fails, appropriate error messages are displayed near the respective fields, and form submission is prevented.
