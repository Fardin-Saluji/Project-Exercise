⏳ Project Exercise 20: Interactive Weather App

This project demonstrates how to build an interactive weather application using HTML, CSS, JavaScript, and DOM manipulation.

📌 Description

The weather app fetches real-time weather data from a public API (like OpenWeatherMap) and displays it in a user-friendly interface. Users can search for the weather by city name. JavaScript’s Fetch API is used to request data, handle JSON responses, and update the DOM with information such as temperature, humidity, and weather conditions. Error handling is included for invalid city names or network issues.

🛠️ Topics Covered

HTML
CSS
JavaScript
DOM

📚 Skills Covered

Using the Fetch API to retrieve data from external APIs

Handling JSON responses

DOM manipulation to display dynamic weather information

Implementing error handling for invalid inputs or network issues
