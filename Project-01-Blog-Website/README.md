# 📝 Styled Blog Page (HTML & CSS)

A simple and clean *static blog website* built using *HTML5 and CSS3*.  
This project focuses on layout design, spacing, typography, and basic styling concepts.

🌐 *Live Demo:*  
https://blog-website-html.vercel.app

---

## 📌 Project Overview

The *Styled Blog Page* is a beginner-friendly frontend project that demonstrates how to:
- Structure a webpage using semantic HTML
- Style content using CSS
- Create a clean blog layout with headers, posts, and footer

This project does *not* use JavaScript or any framework — only *pure HTML & CSS*.
