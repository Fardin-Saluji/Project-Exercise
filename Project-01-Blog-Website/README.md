📝 Project Exercise 1: Blog Website
This project is a simple blog website created using HTML. It focuses on understanding the basic structure of an HTML document and using essential HTML elements to build a static webpage.

📌 Description:-
The blog webpage includes headings, paragraphs, ordered and unordered lists, links, and images. It starts with a proper <!DOCTYPE> declaration and uses the <html>, <head>, and <body> tags to define the page structure.

🛠️ Topic Covered:-
HTML

📚 Skills Covered:-
HTML document structure
Using semantic HTML elements
Embedding images and links
