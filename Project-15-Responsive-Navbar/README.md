📱 Project Exercise 15: Responsive Navbar

This project focuses on creating a responsive navigation bar that adapts smoothly to different screen sizes using HTML and CSS.

📌 Description

The navigation bar displays horizontal menu links on larger screens. On smaller screens, such as mobile devices, it transforms into a hamburger menu. Media queries are used to control responsiveness, and Flexbox is applied for layout management. The hamburger menu is interactive and reveals the navigation links in a dropdown or slide-in style when clicked.

HTML

CSS

📚 Skills Covered

Media queries for responsive design

Flexbox layout management

Positioning and styling navigation menus
