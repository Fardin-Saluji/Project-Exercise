📋 Project Exercise 8: Dynamically Add List Items

This project demonstrates how to dynamically update webpage content using JavaScript and DOM manipulation.

📌 Description

The webpage contains an unordered list and a button. Each time the button is clicked, a new list item is created using JavaScript and added to the list. CSS is used to style the list and button for a clean and user-friendly interface. The project focuses on creating and appending elements dynamically using DOM methods.

JavaScript
